## 🚀 Utilisation

### Ajouter Bishokus à votre serveur

**[➕ Ajouter Bishokus à votre serveur](https://discord.com/api/oauth2/authorize?client_id=854081099638112256&permissions=277582703681&scope=bot%20applications.commands)**

Une fois ajouté, utilisez `/aide` ou `/help` pour voir toutes les commandes disponibles !
